# 🛍️ CasaBella - חנות בוטיק למפות שולחן וטקסטיל

פרויקט גמר Full-Stack המציג מערכת מסחר אלקטרוני (E-commerce) שלמה.

## 🚀 טכנולוגיות בשימוש
* **Frontend:** React, Redux Toolkit, Material UI (MUI), Axios.
* **Backend:** Node.js, Express, MongoDB, JWT, Bcrypt, Multer.

## 🛠️ תכונות עיקריות
### 👤 לקוח:
* רישום והתחברות מאובטחת.
* עגלת קניות דינמית.
* תהליך תשלום (Checkout).
* צפייה בהיסטוריית הזמנות אישית.

### 👑 מנהל (Admin):
* ניהול מוצרים (הוספה, עריכה, מחיקה).
* צפייה בכל ההזמנות שבוצעו באתר כולל פרטי לקוחות.
* הגנת נתיבים (רק מנהל יכול להוסיף מוצרים).

## 📂 מבנה הפרויקט
* `client/` - קוד ה-React. צ מחצ 
* `server/` - קוד ה-Node.js וה-API.
